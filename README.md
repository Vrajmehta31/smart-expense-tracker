# Smart Expense Tracker (MERN + AI Insights)

## Run
Backend: cd backend && cp .env.example .env (add MongoDB Atlas URI) && npm install && npm start
Frontend: cd frontend && npm install && npm run dev  (opens on http://localhost:5173)

## Features
Self-learning auto-categorization, anomaly detection (z-score + duplicate), 3-month weighted forecast,
budget early-warning, subscription detector, interactive dashboard.
